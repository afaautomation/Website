The project

A Domain-Specific AI Knowledge Assistant

Build an application that does more than return a generic response. A knowledge assistant can use a defined collection of documents or information to help answer questions about a particular subject, service, team, or organisation. You will explore the core flow behind it:

  1. Prepare and organise source documents.
  2. Split content into manageable sections.
  3. Generate embeddings from the content.
  4. Store and search the resulting representations in a vector database.
  5. Retrieve relevant information for a user query.
  6. Pass the retrieved context to a language model.
  7. Generate a response informed by the available source material.

Good to know: RAG can improve how relevant an answer is to a supplied knowledge base. It does not guarantee that every generated answer will be correct. Good source data, retrieval quality, evaluation, and suitable safeguards still matter.

FAQ

Frequently asked questions

Is this a beginner Python course?

No. This programme is intended for learners who already have a foundation in Python and programming logic. Learners who are completely new to coding should build those fundamentals first.

What is the difference between using Generative AI and building a Generative AI application?

Using a public AI tool means interacting with a model through an existing product. Building a Generative AI application means integrating a model into software you develop, connecting it to data or tools, and designing how the application handles user requests and responses.

What is RAG?

Retrieval-Augmented Generation (RAG) is an approach that retrieves relevant information from a knowledge source and provides it to a language model as context for generating a response. It can make responses more relevant to the supplied information, but it does not guarantee accuracy.

Do I need to know Python before joining?

Yes. You should be comfortable with core Python concepts and programming logic. Familiarity with web development, databases, or APIs is also useful for this advanced learning path.

What will I build during the programme?

The project direction includes a domain-specific AI knowledge assistant. It uses document processing, embeddings, vector search, and RAG to retrieve relevant context and generate responses through a language model.

Does the programme teach only prompt engineering?

No. Prompt engineering is one part of the learning. The programme also explores full-stack development, API integration, embeddings, vector databases, RAG, AI application frameworks, and the development considerations involved in building AI-powered software.

Does RAG guarantee correct answers?

No. RAG can help a model use relevant information from a supplied knowledge base, but answer quality depends on the source material, retrieval process, model behaviour, and application safeguards. Outputs still need evaluation.
